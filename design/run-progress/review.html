One hero on the overview, not one tile per phase. The order never varies, so the heading stays Getting your first week ready for the whole run; only the step line and the meter move. The meter uses the loop track’s own vocabulary — filled segments in --brand-2, the live one in --brand with a single sweep across it — so it is the one thing on the page that moves, and it is the only primary button on the page.

The page behind it is the real overview. Where the agent is, this week, the stat tiles and the brand kit all render at this point in the live app. The first version replaced the whole page with the tile, which is why it looked bare — the client is meant to see a workspace that is already theirs, with one thing in it still running.

One list, not two. Research and strategy are separate runs on the server, but the client sees one five-step list that fills in. Splitting it would make them watch two progress bars for one outcome.

Steps, not a percentage bar. The runs report a named step, never a percentage, so a bar would be invented. The scan screen already made this choice.

The overview tile has an action, the page does not. On the overview the client is passing through, so the tile offers "Watch it". On the strategy page they are already watching, so there is nothing to press.
